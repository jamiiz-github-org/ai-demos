# Asante Stays — Troubleshooting & Common Issues

This guide applies to all three listings at 4682 Bandini Avenue: the Studio (Unit 4664), the Two-Bedroom (Unit 4664B), and the Shared House. For anything urgent, message the host directly via the booking platform. For emergencies, the emergency contact number is in the welcome guide at your listing.

---

## Wi-Fi

**Wi-Fi not connecting?**
1. Check you're using the correct network: AsanteStays_5G (password: asante2024!)
2. Restart the router — it's the black box on the shelf in the living room. Unplug for 15 seconds, then plug back in. Give it 60 seconds to reconnect.
3. If still not working, message the host.

**Slow connection?**
Try connecting to 5G instead of 2.4G — look for AsanteStays_5G in your Wi-Fi list. The 5G band is faster, especially for video calls.

## Air Conditioning & Heating

**AC not cooling?**
1. Check the thermostat in the hallway — set to COOL, not FAN
2. Make sure the temperature is set below the current room temperature
3. Check that all windows and doors are closed (the AC works much better in a sealed space)
4. If the display shows a filter icon (looks like a grid), the filter needs attention — message the host

**Heater not working?**
1. Set the thermostat to HEAT mode and raise the temperature above the current reading
2. Allow 5–10 minutes for the system to warm up

## Kitchen

**Dishwasher not starting?**
Make sure the door is firmly latched. Press and hold Start for 3 seconds. Pods are in the drawer to the left of the dishwasher.

**Nespresso not working?**
Check there's a pod in the machine and the water tank at the back is filled. The machine needs about 30 seconds to heat up after switching on.

**Oven temperature seems off?**
The oven runs hot — try 10–15 degrees lower than your recipe suggests. Preheat for at least 10 minutes.

---

## TV & Streaming

**TV remote not working?**
Check the batteries — spares are in the kitchen junk drawer. The remote has to be pointed directly at the TV.

**Netflix/Hulu not loading?**
Check the Wi-Fi connection first. If Wi-Fi is fine, restart the TV (hold the power button for 5 seconds) and try again. Do not log out of the streaming accounts.

**TV stuck on a screen?**
Press the Home button on the remote and select the input labelled HDMI1. If you're using your own HDMI device, use the port on the left side of the TV.

---

## Plumbing

**Hot water slow to arrive?**
Run the tap for up to 45 seconds — the boiler takes a moment to warm up, especially in the morning.

**Shower pressure low?**
Check that the valve behind the shower handle is fully open. If pressure is still low after a few minutes, message the host.

**Toilet running after flushing?**
Lift the cistern lid and check the float valve — sometimes it needs a gentle adjustment. Message the host if it doesn't stop within a few minutes.

---

## Locks & Entry

**Smart lock not accepting the code?**
Make sure you're entering the code sent to you (not a previous guest's code). Press the Schlage button first to wake the lock, then enter the code and press Schlage again. If it still doesn't work, message the host immediately — there is a backup key in the lockbox.

**Lockbox not opening?**
The lockbox code is different from the door code. It's included in your check-in message. Pull the shutter down firmly while entering the code.

## Noise & Neighbours

**Hearing noise from outside?**
Riverside is a residential neighbourhood but there can be street noise. Extra earplugs are in the bathroom cabinet. The bedroom blackout curtains also help dampen sound.
