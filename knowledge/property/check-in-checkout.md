# Asante Stays — Check-In & Checkout Guide

All listings are at **4682 Bandini Avenue, Riverside, CA**. Entry differs per unit — see below.

---

## Check-In Times
- **Standard check-in:** 3:00 PM
- **Early check-in (from 1:00 PM):** Available on request — message the host the night before. Depends on the previous guest's checkout.
- **Late arrival:** No problem — smart locks and lockboxes work at any hour. Just let us know.

---

## Check-In by Listing

### Studio — Unit 4664
1. You'll receive your door code by message 2 hours before check-in
2. Park in the driveway or street
3. Walk to **the door right next to the garage** — that's your entrance
4. Enter your code on the smart lock keypad to get in
5. The welcome guide is on the kitchen counter

### Two-Bedroom — Unit 4664B
1. You'll receive your entry code by message 2 hours before check-in
2. Park in the driveway or street
3. Walk to **the entrance on the right side of the building**
4. Enter your code to unlock the door
5. The welcome guide is on the kitchen counter

### Shared House
1. You'll receive your entry instructions by message 2 hours before check-in
2. Park in the driveway — space for multiple vehicles
3. Enter via the main house front door using the code provided
4. The welcome guide is on the dining table

## What to Expect on Arrival
- Beds are freshly made with clean linens
- Towels are laid out in the bathroom
- Coffee, tea, and basic pantry items are stocked
- The Wi-Fi password is on the welcome card and in the welcome guide
- The TV is ready to use — streaming apps are pre-loaded

---

## Checkout

**Standard checkout:** 11:00 AM
**Late checkout (until 1:00 PM):** Available for an additional fee — request the night before, subject to availability

### Before You Leave (All Listings)
1. Strip the beds and leave used towels in the bathroom
2. Wash up any dishes or run the dishwasher if available
3. Put rubbish in the bin bags provided and leave in the designated bin area
4. Close and lock all windows and doors
5. Leave any keys or key cards on the kitchen counter
6. Lock up as you leave — your access code remains active until noon

---

## If You Can't Find Your Entry Point
If you arrive and can't locate the right entrance, message the host immediately via the booking platform. Each unit's entry is described above, but we're always available to help.

---

## Questions on Arrival?
Message the host via the booking platform at any time. For urgent after-hours issues, the emergency contact number is in the welcome guide at each listing.
